ОП.08 «Основы проектирования баз данных»
Набор 2025 · 2025–2026 учебный год

Организация запросов SQL: понятия, синтаксис и типы данных

Результат изучения

Выбрать типы данных и составить корректный SQL-запрос.

Ключевые понятия

SQL, DDL, DML, типы данных, NULL, выражение и параметр запроса.

Работайте со сквозным кейсом «Учебная библиотека»: читатели берут экземпляры книг, библиотекарь фиксирует выдачу и возврат, а система сохраняет непротиворечивую историю.

Правило проектирования

Сначала зафиксируйте факт предметной области, затем выберите сущности и связи, после этого определите ключи, типы и ограничения. Не заменяйте ограничение БД только проверкой в форме.

Пример SQL

CREATE TABLE reservations (reservation_id INTEGER PRIMARY KEY, reader_id INTEGER NOT NULL REFERENCES readers(reader_id), reserved_at TIMESTAMP NOT NULL, active BOOLEAN NOT NULL DEFAULT TRUE);

Прочитайте код: назовите объект, ключи, ограничение и правило предметной области, которое они выражают.

Мини-задание

  1. Объясните разницу между NULL, пустой строкой и нулём на примере полей базы библиотеки.
  2. Назовите одно недопустимое состояние данных.
  3. Запишите ограничение или запрос, который его предотвратит либо обнаружит.

Критерии проверки

КритерийНаблюдаемый результат
КорректностьЗапрос или модель отражает условие и использует подходящие ограничения.
ЦелостностьКлючи, связи и проверки не допускают противоречивые данные.
ОбоснованиеКаждое решение связано с требованием предметной области.
