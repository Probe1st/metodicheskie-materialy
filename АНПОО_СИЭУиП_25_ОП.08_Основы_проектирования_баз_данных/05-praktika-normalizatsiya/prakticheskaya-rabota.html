Практическая работа № 2. Нормализация реляционной БД

Результат работы

Нормализовать исходную таблицу до третьей нормальной формы.

Исходные данные

Сквозной кейс — учебная библиотека. Используйте сущности readers, books, copies и loans; при необходимости добавляйте только обоснованные сущности.

Практическая работа

  1. Разделите таблицу «Книга–автор–телефон автора» на отношения без повторяющихся групп.
  2. Выполните или адаптируйте SQL-код для своей схемы.
  3. Проверьте один корректный и один некорректный случай.
  4. Сохраните схему, запросы и краткий вывод с результатами проверки.
CREATE TABLE authors (author_id INTEGER PRIMARY KEY, full_name TEXT NOT NULL);
CREATE TABLE book_authors (book_id INTEGER REFERENCES books(book_id), author_id INTEGER REFERENCES authors(author_id), PRIMARY KEY (book_id, author_id));
