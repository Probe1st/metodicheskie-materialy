Цель

Закрепить концептуальная, логическая и физическая модель; нормализация и целостность на новом сценарии.

  1. Замените библиотеку на прокат спортивного инвентаря.
  2. Выделите минимум три сущности и назначьте каждой первичный ключ.
  3. Сформулируйте один запрос или ограничение по образцу.
  4. Приведите один пример данных, который должен быть отклонён.
CREATE TABLE copies (copy_id INTEGER PRIMARY KEY, book_id INTEGER NOT NULL REFERENCES books(book_id), inventory_no TEXT UNIQUE NOT NULL, status TEXT NOT NULL CHECK (status IN ('available', 'loaned', 'repair')));
