## 1. Детальная критериальная матрица (максимум 4 балла)

### Критерий 1. Спецификация и инженерный анализ характеристик узлов ввода (0–2 балла)
Оценивается полнота и инженерная корректность заполнения таблицы 5 аппаратных узлов (переключатели, матрица/NKRO, форм-фактор/эргономика, оптический сенсор мыши, интерфейс подключения и polling rate) с учётом выбранного профиля:
- **2 балла**: Все 5 аппаратных узлов специфицированы технически грамотно. Выбор каждого узла исчерпывающе аргументирован спецификой профиля (например, для CAD — отключение Angle Snapping и аппаратного ускорения, для диспетчера — герметичность IP68 и проводное экранирование, для машинистки — тактильный бамп и сплит-корпус, для программиста — слои QMK/VIA и формат TKL/65%).
- **1 балл**: Допущены 1–2 неточности или неполноты (например, указан тип переключателей без объяснения физики срабатывания, либо не упомянута роль диодов при анализе NKRO), но общий профиль оборудования сформирован непротиворечиво.
- **0 баллов**: Грубые инженерные ошибки (например, рекомендация Bluetooth 90 Гц для высокоточного CAD, непонимание разницы между 2KRO и NKRO, путаница оптических и мембранных механизмов), пропущено более двух узлов.

### Критерий 2. Протокол настройки параметров ОС и расчёт частоты опроса / задержки ввода (0–1 балл)
Оценивается математическая точность расчета составляющих аппаратной задержки ввода ($T_{hw} = T_{mech} + T_{scan} + T_{debounce} + T_{usb\_poll} + T_{os}$), перевод частоты опроса в период ($T = 1000 / F$) и корректность параметров в ОС (Repeat Delay, Repeat Rate, отключение Enhance Pointer Precision, выбор CPI):
- **1 балл**: Все расчёты выполнены математически безошибочно. Правильно учтено среднее время ожидания опроса шины ($T_{usb\_poll} = T_{poll} / 2$). Для механических контактов корректно заложен дебаунс (5–10 мс), для оптических/Hall Effect указано 0 мс. Протокол настройки ОС заполнен с ясным пониманием физического смысла параметров.
- **0 баллов**: Допущены арифметические или методологические ошибки (например, период 125 Гц посчитан как 12.5 мс вместо 8 мс, перепутаны частота и период, проигнорирован дебаунсинг механики), параметры ОС не заполнены или указаны неверно (например, совет оставить акселерацию мыши включенной для CAD).

### Критерий 3. Проверка и аналитическое заключение (0–1 балл)
Оценивается аргументированность итогового вывода:
- **1 балл**: Сформулирован зрелый технический вывод, связывающий физические параметры элементной базы (отсутствие дребезга, стабильность оптического потока, высокая частота шины) с измеряемыми показателями надежности, снижением профессионального утомления оператора и ростом скорости/точности работы.
- **0 баллов**: Вывод носит формальный, шаблонный характер («все настроено хорошо, работать удобно») без опоры на результаты измерений и расчетов.

## 2. Эталонные решения по 4 прикладным вариантам

### Вариант 1: Рабочее место оператора набора текста / машинистки
1. **Тип переключателей**: Тактильные механические (Cherry MX Brown / Gateron Brown) или купольные пружинные (Topre).  
   *Обоснование*: Выраженный тактильный бамп на середине хода (1.8–2.0 мм) позволяет оператору почувствовать факт срабатывания без удара пальцев об упор пластины (bottom-out), что предотвращает микротравмы суставов и синдром запястного канала (RSI) при 8-часовом наборе.
2. **Схемотехника матрицы**: NKRO (диодная развязка на каждой клавише).  
   *Обоснование*: Исключает блокировку клавиш (Key Jamming) при высокой скорости набора (аккордовый ввод, быстрые комбинации клавиш со скоростью более 400 симв/мин).
3. **Форм-фактор и эргономика**: Эргономичный сплит (раздельная клавиатура Alice / Ergodox) с отрицательным наклоном подставки под ладони. Мышь — вертикальная эргономичная (хват «рукопожатие» с углом 57°).  
   *Обоснование*: Устраняет неестественную пронацию предплечья и статический зажим лучезапястного сустава.
4. **Сенсор мыши**: Оптический светодиодный сенсор 1000–1600 CPI.  
   *Обоснование*: Работа преимущественно текстовая, сверхвысокие CPI не требуются.
5. **Интерфейс и Polling Rate**: Проводной USB или радиоканал 2.4 ГГц, частота опроса 500–1000 Гц.
6. **Расчет задержки ввода ($T_{hw}$)**:  
   $T_{mech} = 5.0$ мс (ход 2 мм при средней скорости нажатия) + $T_{scan} = 1.0$ мс (1000 Гц) + $T_{debounce} = 5.0$ мс (механические контакты) + $T_{usb\_poll} = 0.5$ мс (1000 Гц, среднее $1.0 / 2$) + $T_{os} = 1.5$ мс = **13.0 мс**.
7. **Параметры ОС**: Repeat Delay = Короткая (250 мс), Repeat Rate = Максимальная (30 симв/с). Указатель мыши: средняя чувствительность (6/11 в Windows).

---

### Вариант 2: Рабочее место CAD-проектировщика / инженера
1. **Тип переключателей**: Линейные механические (Cherry MX Red / Silent Red) с вибродемпфирующими кольцами O-ring.  
   *Обоснование*: Предсказуемое плавное нажатие, отсутствие отвлекающего акустического шума в инженерном отделе.
2. **Схемотехника матрицы**: NKRO (N-Key Rollover).  
   *Обоснование*: Безошибочный ввод многоклавишных шорткатов в САПР (например, Ctrl+Shift+Alt+клик).
3. **Форм-фактор**: Полноразмерный (100% с выделенным NumPad) для быстрого ввода числовых координат и размеров деталей, плюс блок макро-клавиш.
4. **Сенсор мыши**: Прецизионный оптический сенсор без аппаратного сглаживания и без интерполяции (PixArt PAW3395/3370), честные 1600–2400 CPI. **Строго отключены Angle Snapping и Hardware Acceleration**.  
   *Обоснование*: Angle Snapping принудительно «выпрямляет» движение курсора в горизонт/вертикаль, что делает невозможным точную привязку к дугам, окружностям и сплайнам. Акселерация разрушает мышечную координацию.
5. **Интерфейс и Polling Rate**: Проводной USB HID, экранированный кабель, 1000 Гц ($T_{poll} = 1.0$ мс).
6. **Расчет задержки ввода ($T_{hw}$)**:  
   $T_{mech} = 4.0$ мс + $T_{scan} = 0.5$ мс (2000 Гц) + $T_{debounce} = 5.0$ мс + $T_{usb\_poll} = 0.5$ мс + $T_{os} = 1.0$ мс = **11.0 мс**.
7. **Параметры ОС**: «Включить повышенную точность указателя» — **ОТКЛЮЧЕНО** (устранение программной кривой разгона), Raw Input — **ВКЛЮЧЕНО**.

---

### Вариант 3: Терминал оператора диспетчерской службы / промышленная среда
1. **Тип переключателей**: Герметичные мембранные с силиконовым куполом или магнитоуправляемые герконы (Reed Switches).  
   *Обоснование*: Полная герметичность, отсутствие открытых контактов, стойкость к пыли, влаге, агрессивным дезинфицирующим растворам (степень защиты IP68).
2. **Схемотехника матрицы**: 2KRO / 6KRO с аппаратной защитой от помех (RC-фильтры на линиях строк).  
   *Обоснование*: В условиях работы мощных электроприводов и контакторов электромагнитные наводки могут вызвать ложные срабатывания; помехозащита важнее геймерского NKRO.
3. **Форм-фактор**: Промышленный металлический антивандальный корпус со встроенным трекболом или сенсорной панелью.
4. **Сенсор мыши/манипулятора**: Промышленный оптический трекбол со степенью защиты IP65/IP68. В манипуляторе нет открытого оптического окна снизу, грязь с коврика не забивает сенсор.
5. **Интерфейс и Polling Rate**: Исключительно проводной USB с ферритовыми кольцами и экранированием (или промышленный RS-422/RS-485 через мост). Частота опроса 250–500 Гц ($T = 2–4$ мс).  
   *Обоснование*: Беспроводные интерфейсы (Bluetooth / Wi-Fi) категорически запрещены из-за уязвимости к радиопомехам цеха и риска потери контроля над технологическим процессом.
6. **Расчет задержки ввода ($T_{hw}$)**:  
   $T_{mech} = 8.0$ мс (упругая силиконовая мембрана) + $T_{scan} = 2.0$ мс (500 Гц с аппаратной фильтрацией) + $T_{debounce} = 10.0$ мс + $T_{usb\_poll} = 1.0$ мс (500 Гц, среднее) + $T_{os} = 2.0$ мс = **23.0 мс**.
7. **Параметры ОС**: Repeat Delay = 500 мс (предотвращение случайных повторных команд при вибрациях пульта), Repeat Rate = Умеренная (15 симв/с).

---

### Вариант 4: Рабочее место программиста (разработчика ПО)
1. **Тип переключателей**: Оптические (Gateron Optical) или на эффекте Холла (Hall Effect Switches) либо легкая тактильная механика.  
   *Обоснование*: Нулевой дебаунсинг ($T_{debounce} = 0$), настраиваемая точка срабатывания от 0.5 мм (Rapid Trigger), легкость долгого кодинга без усталости.
2. **Схемотехника матрицы**: Полный аппаратный NKRO с индивидуальными диодами.  
   *Обоснование*: Поддержка сложных аккордовых комбинаций сред разработки (IDE) и терминальных эмуляторов.
3. **Форм-фактор**: Компактный 65% или 75% / TKL. Контроллер с поддержкой свободных прошивок **QMK / VIA / ZMK**.  
   *Обоснование*: Убирается блок NumPad, расстояние от правой руки до мыши сокращается на 10–12 см, снижая нагрузку на правое плечо. Поддержка прошивки позволяет запрограммировать слои Fn (стрелки и навигация на домашнем ряду `HJKL`), замену CapsLock на Ctrl на уровне микроконтроллера.
4. **Сенсор мыши**: Оптический светодиодный сенсор 1600–3200 CPI с симметричным легким корпусом (до 60 г).
5. **Интерфейс и Polling Rate**: Проводной USB или 2.4 ГГц с низкой задержкой, 1000 Гц.
6. **Расчет задержки ввода ($T_{hw}$)**:  
   $T_{mech} = 1.5$ мс (срабатывание на 0.5 мм хода) + $T_{scan} = 0.5$ мс (2000 Гц) + $T_{debounce} = 0.0$ мс (оптика/Холл) + $T_{usb\_poll} = 0.5$ мс (1000 Гц) + $T_{os} = 0.8$ мс = **3.3 мс**.
7. **Параметры ОС**: Repeat Delay = Минимальная (250 мс), Repeat Rate = Максимальная (30–40 симв/с) для быстрого перемещения каретки по строкам кода.

## 3. Эталон решения резервного домашнего задания (`domashnee_zadanie.html`)

1. **Конфигурация А (Офисная станция)**:  
   $T_{hw} = T_{mech} (8.0) + T_{scan} (1.0) + T_{debounce} (8.0) + T_{usb\_poll} (4.0) + T_{os} (2.0) = \mathbf{23.0\text{ мс}}$.
2. **Конфигурация Б (Профессиональная станция)**:  
   $T_{hw} = T_{mech} (2.5) + T_{scan} (0.25) + T_{debounce} (0.0) + T_{usb\_poll} (0.5) + T_{os} (0.8) = \mathbf{4.05\text{ мс}}$.
3. **Выигрыш во времени**:  
   $\Delta T = 23.0 - 4.05 = \mathbf{18.95\text{ мс}}$.  
   Коэффициент ускорения: $23.0 / 4.05 \approx \mathbf{5.68\text{ раза}}$.

## 4. Классификатор типичных ошибок обучающихся

| Ошибка | В чем выражается | Последствия для оценки |
| :--- | :--- | :--- |
| **Путаница DPI и CPI** | Студент пишет: «DPI — это скорость движения мыши по коврику». | Минус 0.5 б. по Критерию 1. Требуется понимание, что CPI — это физические отсчеты оптического потока. |
| **Ошибочный расчёт периода шины** | Студент указывает $T_{usb\_poll} = 125$ мс или не делит период пополам для вычисления среднего ожидания. | Минус 0.5 б. по Критерию 2. Период $T = 1000/125 = 8$ мс, среднее время ожидания прерывания равно $4$ мс. |
| **Игнорирование дебаунсинга** | Студент ставит $T_{debounce} = 0$ для механических контактов с витой пружиной. | Минус 0.5 б. по Критерию 2. Упругий металл всегда имеет дребезг 5–10 мс. Нулевой дебаунс только у оптики и Холла. |
| **Сохранение акселерации для CAD** | Студент рекомендует включить «Повышенную точность указателя» для инженерного черчения. | Минус 0.5 б. по Критерию 2. Акселерация искажает масштабирование движений руки при наведении на узлы чертежа. |
| **Рекомендация Bluetooth для АСУТП** | Студент выбирает беспроводную мышь/клавиатуру BLE для диспетчера взрывоопасного или промышленного производства. | Минус 1.0 б. по Критерию 1. Нарушение требований промышленной электромагнитной совместимости и отказоустойчивости. |
