Домашнее задание - Устройство клавиатуры и мыши, настройка параметров работы клавиатуры и мыши

Инструкция: изучите методический пример аппаратного расчета задержки ввода (Input Lag), выполните практические расчеты для двух типовых конфигураций и заполните протокол настройки параметров ОС.

Выполняйте только если преподаватель назначил это задание. Срок сдачи сообщит преподаватель.

1. Инженерный образец: Расчёт задержки конвейера ввода (Input Lag Pipeline)

Совокупное время реакции системы от момента касания клавиши/мыши пальцем до обновления пикселей на дисплее формируется последовательным сложением времени прохождения сигнала по аппаратным и программным узлам:

Формула конвейера задержки:
T_total = T_mech + T_scan + T_debounce + T_usb_poll + T_os + T_render + T_display

Пример расчета для базового офисного ПК:
1. T_mech (ход клавиши до срабатывания): мембрана 4.0 мм при скорости пальца 0.4 м/с = 10.0 мс.
2. T_scan (период сканирования матрицы МК): 500 Гц = 2.0 мс.
3. T_debounce (устранение дребезга контактов): 10.0 мс.
4. T_usb_poll (опрос USB HID 125 Гц, период 8 мс): среднее время ожидания = 4.0 мс.
5. T_os (драйвер HID + буфер очереди оконных сообщений ОС): 2.5 мс.
6. T_render + T_display (кадр GPU + развертка монитора 60 Гц, период 16.6 мс): среднее = 16.6 мс.
Итоговая задержка офисного тракта: 10 + 2 + 10 + 4 + 2.5 + 16.6 = 45.1 мс.

2. Практический расчет: Сравнительный анализ офисной и киберспортивной периферии

Используя эталонную методику конвейера задержки, рассчитайте аппаратную задержку контроллера ввода (без учета рендера GPU и монитора, т.е. T_hardware = T_mech + T_scan + T_debounce + T_usb_poll + T_os) для двух заданных конфигураций.

Параметр тракта ввода Конфигурация А: Офисная станция (Мембрана + USB 125 Гц) Конфигурация Б: Профессиональная станция (Оптика + USB 1000 Гц)
Механический ход (T_mech) 3.5 мм (ход до упора): 8.0 мс 1.2 мм (срабатывание на раннем ходе): 2.5 мс
Сканирование матрицы (T_scan) Период 1000 Гц: 1.0 мс Период 4000 Гц: 0.25 мс
Дебаунсинг (T_debounce) Мембранно-проводящий пятак: 8.0 мс Оптический затвор (нет дребезга): 0.0 мс
Опрос USB HID (T_usb_poll) Частота 125 Гц (период 8.0 мс, среднее): 4.0 мс Частота 1000 Гц (период 1.0 мс, среднее): 0.5 мс
Драйвер и стек ОС (T_os) Стандартная оконная очередь: 2.0 мс Драйвер Raw Input без сглаживания: 0.8 мс
