Логические элементы. Базовые схемы

От напряжения к логическим переменным

В цифровой схемотехнике непрерывные электрические сигналы дискретизируются по двум диапазонам напряжений:

  • Низкий потенциал (0 В .. 0,8 В) → Логический 0 (False / ЛОЖЬ).
  • Высокий потенциал (2,4 В .. 5,0 В) → Логическая 1 (True / ИСТИНА).

Математический фундамент анализа и проектирования таких цепей — булева алгебра (алгебра логики).

Функционально полный базис {НЕ, И, ИЛИ}

Любая вычислительная логическая функция произвольной сложности может быть синтезирована из трех элементарных вентилей:

  • Инвертор (НЕ / NOT): формирует противоположенный уровень сигнала.
  • Конъюнктор (И / AND): активен только при одновременной подаче всех единиц.
  • Дизъюнктор (ИЛИ / OR): формирует единицу при наличии единицы хотя бы на одном входе.

Инвертор (Логическое отрицание НЕ)

Y = ¬A = A̅

Единственный вход, единственный выход. В транзисторной реализации представляет собой базовый ключ: при подаче напряжения на базу/затвор выходной каскад шунтируется на землю.

Y = A ∧ B = A · B

Y = A ∨ B = A + B

Универсальные вентили: И-НЕ и ИЛИ-НЕ

В полупроводниковой промышленности монолитные вентили NAND (И-НЕ) и NOR (ИЛИ-НЕ) технологически проще и быстрее, чем чистые И / ИЛИ.

  • Базис Шеффера (И-НЕ): Y = ¬(A ∧ B). Вентиль НЕ получается объединением входов.
  • Базис Пирса (ИЛИ-НЕ): Y = ¬(A ∨ B).
  • По законам де Моргана через любой из этих элементов можно выразить весь базис {И, ИЛИ, НЕ}.

Понятие комбинационной схемы

Комбинационной схемой называется устройство, в котором логическое состояние выходов в любой момент времени однозначно задается набором входных сигналов.

  • В комбинационных схемах нет обратных связей и нет элементов памяти.
  • Таблица истинности полностью описывает функционал схемы.
  • Для схемы с n входами таблица истинности содержит строго 2n строк.

Синтез схемы: F = (A ∧ B̅) ∨ (B ∧ C)

Схема управляет узлом коммутации на основе трех условий A, B, C:

Вход B →
НЕ
→ Промежуточный узел X1 = B̅
Вход A + X1 →
И (1)
→ Промежуточный узел X2 = A ∧ B̅
Вход B + Вход C →
И (2)
→ Промежуточный узел X3 = B ∧ C
X2 + X3 →
ИЛИ
→ Выход F = X2 ∨ X3

Типовая ошибка: потеря инверсии

Что произойдет, если проводник подключен ко входу B напрямую, минуя инвертор НЕ?

  • Ошибочное выражение: Ferr = (A land B) lor (B land C) = B land (A lor C).
  • На наборе `A=1, B=0, C=0` эталон выдает 1, а поврежденная схема — 0!
  • Схема перестает реагировать на управляющий сигнал A при нулевом значении шины B.

Самопроверка: вентиль XOR

Двухвходовый логический элемент «Исключающее ИЛИ» (XOR) описывается формулой:

Y = (A ∧ B̅) ∨ (A̅ ∧ B)

Вопрос: Чему равно выходное значение Y при комбинациях входных сигналов:

  • 1) A = 1, B = 1 → ?
  • 2) A = 1, B = 0 → ?

Подсказка: единичный уровень возникает только при несовпадении сигналов.

Самопроверка: закон де Моргана

Преобразуйте логическое выражение для инвертора Шеффера:

¬(A ∧ B) = ?
  • Вариант 1: ¬A ∧ ¬B
  • Вариант 2: ¬A ∨ ¬B

Правило де Моргана: Отрицание конъюнкции равно дизъюнкции отрицаний!

Резюме: от вентилей к микропроцессору

  • Логические вентили — элементарные кирпичики всех узлов ЭВМ.
  • Комбинация нескольких сотен вентилей образует сумматоры и компараторы.
  • Добавление обратной связи создает триггеры — ячейки статической памяти (SRAM).
  • Миллиарды таких транзисторных структур в кристалле кремния формируют современный процессор.
