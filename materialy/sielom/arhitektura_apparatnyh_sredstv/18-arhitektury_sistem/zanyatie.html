Задание 3. Анализ масштабируемости: закон Амдала vs закон Густафсона-Барсиса

Сравните предельное ускорение многопроцессорных систем при фиксированном объеме задачи (закон Амдала: S_Amdahl = 1 / (s + p / n)) и при масштабировании объема задачи пропорционально числу процессоров (закон Густафсона-Барсиса: S_Gustafson = s + p × n = 1 + (n - 1) × p), где s — доля последовательного кода, p = 1 - s — доля параллельного кода, n — число узлов/ядер.

n = 8 s = 0.05 (p = 0.95)
n = 64 s = 0.05 (p = 0.95)
