Единицы количества информации: бит и байт

В физических цепях ЭВМ информация передаётся дискретными электрическими потенциалами.

  • Бит (bit) — наименьшая неделимая мера информации, фиксирующая двоичный выбор (0 или 1).
  • Байт (Byte) — совокупность из 8 бит, базовая адресуемая единица оперативной памяти.
  • Двоичные приставки (IEC / ГОСТ): 1 Кбайт (KiB) = 1024 байта (210), 1 Мбайт (MiB) = 1024 Кбайт (220).

Суть: Единицы информации измеряют емкость физических ячеек и линий связи, но не определяют их смысл.

Емкость ячейки памяти vs Смысл данных

Один и тот же байт 11111111 в ячейке памяти процессора может интерпретироваться совершенно по-разному:

Unsigned uint8

Беззнаковое число: 25510. Все 8 разрядов отвечают за величину числа.

Signed int8

Знаковое число в доп. коде: -110. Старший бит 1 означает отрицательный знак.

Символ (ASCII / CP1251)

В кодовой таблице Windows-1251 код 0xFF соответствует букве «я».

Вывод: Процессор выполняет операции согласно коду команды, наделяя биты смыслом.

Формы представления целых чисел в ЭВМ

Для представления чисел со знаком в регистрах процессора старший бит (MSB) резервируется под знак: 0 — положительное число, 1 — отрицательное число.

  • Прямой код: Знак + абсолютная величина. Неудобен: два нуля (+0 и -0), сумма требует разных схем.
  • Обратный код: Знак + побитовая инверсия модуля. Сохраняет два нуля и циклический перенос.
  • Дополнительный код: Обратный код + 1 к младшему разряду. Общепринятый мировой стандарт в процессорах.

Алгоритм построения дополнительного кода

Пошаговый разбор для числа -4310 в 8-разрядной сетке:

  1. Модуль |-43| = 4310 = 32 + 8 + 2 + 1 = 001010112.
  2. Прямой код: 10101011 (знаковый бит 1).
  3. Обратный код (инверсия модуля): 11010100.
  4. Дополнительный код (обратный код + 1): 
        11010100
  + 00000001
  ----------
    11010101  (дополнительный код числа -43)

Отрицательный вес старшего бита: -128 + 64 + 16 + 4 + 1 = -4310.

Замена вычитания сложением на сумматоре

Главное достоинство дополнительного кода: A - B = A + [-B]доп. АЛУ не требует отдельной схемы вычитателя!

Пример: 58 - 43 (или 58 + (-43)) в 8-разрядном сумматоре:

         1 1 1 1   1        (поразрядные переносы)
         0 0 1 1 1 0 1 0    (+58)
       + 1 1 0 1 0 1 0 1    (-43 в доп. коде)
       -----------------
       1 0 0 0 0 1 1 1 1    (перенос 1 за пределы 8 бит отбрасывается)

В 8-битном регистре: 00001111 = 15 (десятичная проверка: 58 - 43 = 15).

Флаги состояния процессора: CF, OF, ZF, SF

После каждого арифметического действия в регистре флагов (FLAGS) фиксируются признаки:

  • CF (Carry Flag): перенос из старшего разряда. Сигнализирует о переполнении беззнаковых чисел (0 ... 255).
  • OF (Overflow Flag): знаковое переполнение. Сигнализирует о выходе за диапазон знаковых чисел ([-128 ... +127]).
  • ZF (Zero Flag): равен 1, если результат равен точно нулю.
  • SF (Sign Flag): копия старшего (знакового) бита результата.

Контрпример: аппаратное знаковое переполнение (OF)

Что произойдёт, если сложить два положительных числа 9510 + 6510 в 8-битном знаковом формате?

         0 1 0 1 1 1 1 1   (+95)
       + 0 1 0 0 0 0 0 1   (+65)
       -----------------
         1 0 1 0 0 0 0 0   (-96 в знаковом int8 ?!)

Причина парадокса: 95 + 65 = 160, что превышает максимальный лимит +127. Единица переноса попала в знаковый бит.

Аппаратная фиксация: OF = C6 ⊕ C7 = 1 ⊕ 0 = 1. Процессор выставил флаг знакового переполнения!

Поразрядные операции: AND и OR

Выполняются над каждым битом параллельно и независимо (без переносов):

AND (Конъюнкция / Маскирование)

Сброс битов в 0. Умножение на 0 обнуляет разряд, на 1 сохраняет значение.

  11011010
& 00001111  (маска)
----------
  00001010

OR (Дизъюнкция / Установка)

Принудительная установка битов в 1 без изменения остальных разрядов.

  11011010
| 00100001  (маска)
----------
  11111011

Поразрядные операции: XOR и NOT

Инверсия состояний и управление битовыми триггерами:

XOR (Исключающее ИЛИ)

Инвертирует биты там, где в маске стоит 1. Используется для обнуления регистров: XOR EAX, EAX быстрее записи нуля!

  11011010
^ 00000110  (маска)
----------
  11011100

NOT (Побитовая инверсия)

Унарная операция: переворачивает все разряды на противоположные (0 → 1, 1 → 0). Базовый этап построения обратного кода.

~ 00101011
----------
  11010100

Архитектурные инварианты занятия

  • Бит и байт задают емкость физического носителя, семантика определяется инструкцией.
  • Дополнительный код позволяет использовать один и тот же сумматор как для сложения, так и для вычитания.
  • Флаги процессора строго разграничивают режимы: CF фиксирует перенос в беззнаковой арифметике, OF — переполнение в знаковой.
  • Побитовые логические операции обеспечивают прямой аппаратный контроль над отдельными выводами и регистрами чипов.
