## 1. Эталонные решения заданий аудиторного занятия (`zanyatie.html`)

### Задание 1. Двоичная арифметика и переполнение разрядной сетки
**Условие:**
Сложить два числа в 8-разрядной сетке без знака:
$A = 10110110_2$ ($182_{10}$), $B = 01101101_2$ ($109_{10}$).
Определить результат сложения, значение бита переноса ($C_{out}$) и зафиксировать, возникает ли переполнение беззнаковой 8-битной сетки.

**Эталонное решение:**
```
  Поразрядный перенос:  1 1 1 1 1 1 0 0
                  A:    1 0 1 1 0 1 1 0  (182)
                + B:    0 1 1 0 1 1 0 1  (109)
  -------------------------------------------
             Сумма:   1 0 0 1 0 0 0 1 1  (291)
```
- Младшие 8 бит результата в регистре: `00100011` ($35_{10}$).
- Бит переноса из 7-го (старшего) разряда: $C_{out} = 1$.
- Проверка переполнения: диапазон беззнакового 8-битного байта от 0 до 255. Сумма $182 + 109 = 291 > 255$. Регистр сохраняет только $291 \pmod{256} = 35$. Возникает беззнаковое переполнение (unsigned overflow), аппаратный флаг переноса $CF = 1$.

### Задание 2. Поразрядные логические операции (битовые маски)
**Условие:**
Дано состояние аппаратного регистра состояния устройства $R = 11011010_2$.
1. С помощью операции `AND` наложить маску `00001111` для выделения младшей тетрады (nibble).
2. С помощью операции `OR` установить в исходном значении $R$ биты 0 и 5 в 1 (маска `00100001`).
3. С помощью операции `XOR` инвертировать биты 1 и 2 в исходном значении $R$ (маска `00000110`).

**Эталонное решение:**
1. Выделение младшей тетрады (`AND`):
```
    R:     1 1 0 1 1 0 1 0
  MASK:    0 0 0 0 1 1 1 1  (0x0F)
  ------------------------
  RES1:    0 0 0 0 1 0 1 0  (0x0A, 10_10)
```
2. Установка битов 0 и 5 в единицу (`OR`):
```
    R:     1 1 0 1 1 0 1 0
  MASK:    0 0 1 0 0 0 0 1  (0x21)
  ------------------------
  RES2:    1 1 1 1 1 0 1 1  (0xFB, 251_10)
```
3. Инвертирование битов 1 и 2 (`XOR`):
```
    R:     1 1 0 1 1 0 1 0
  MASK:    0 0 0 0 0 1 1 0  (0x06)
  ------------------------
  RES3:    1 1 0 1 1 1 0 0  (0xDC, 220_10)
```

### Задание 3. Различение единиц количества информации и формата хранения
**Условие:**
1. Текстовый буфер содержит $64$ Кбайт данных. Выразить этот объём строго в битах и в байтах, пояснив различие между метрическими ($10^3$) и двоичными ($2^{10}$) приставками.
2. В памяти зафиксирована последовательность из 8 бит: `11111111`. Объяснить, почему бит как единица измерения информации не определяет числовое значение этой ячейки, и привести три различных числовых/символьных значения одного и того же байта в зависимости от интерпретации (беззнаковое число, дополнительный код, кодировка ASCII/ANSI).

**Эталонное решение:**
1. Расчёт объёма:
   - $1\text{ Кбайт} = 1024\text{ байт} = 2^{10}\text{ байт}$.
   - $64\text{ Кбайт} = 64 \times 1024 = 65\,536\text{ байт}$.
   - В битах: $65\,536 \times 8 = 524\,288\text{ бит}$ (или $2^6 \times 2^{10} \times 2^3 = 2^{19}\text{ бит}$).
   - Пояснение: В стандартах ГОСТ Р МЭК 60027-2 и IEC приставка «кило» в вычислительной технике традиционно обозначала $2^{10} = 1024$ (кибибайт, KiB), тогда как в физике и сетях SI-приставка $k = 10^3 = 1000$. Бит фиксирует логическую меру объёма ячеек (двоичный выбор 0 или 1).
2. Различие объёма информации и числового кода:
   - Объем информации ячейки равен ровно 8 бит (1 байт) независимо от того, какие данные в ней записаны. Бит как единица измерения отражает количество двоичных разрядов физического носителя, но не семантику (смысл) данных.
   - Три интерпретации байта `11111111`:
     а) Беззнаковое целое число (`unsigned uint8`): $\sum_{i=0}^7 2^i = 255_{10}$.
     б) Знаковое целое в дополнительном коде (`signed int8`): старший бит знака 1 означает отрицательное число; модуль вычисляется инверсией и добавлением 1: $\text{not}(11111111) = 00000000 \to 00000000 + 1 = 1 \implies -1_{10}$.
     в) Знаковое целое в прямом коде: старший бит 1 (знак «-»), младшие 7 бит `1111111` ($127$) $\implies -127_{10}$ (или код «отрицательного нуля» в модификациях). В таблицах кодировок (например, CP1251) код `0xFF` отображает символ `я` русского алфавита, а в Latin-1 — символ `ÿ`.

### Задание 4. Индивидуальный продукт: представление отрицательных чисел в прямом, обратном и дополнительном кодах (8 бит)
**Условие:**
Для заданного отрицательного числа $X = -43_{10}$ в 8-разрядной сетке:
1. Записать модуль числа в двоичной системе.
2. Составить прямой код ($[X]_{\text{пр}}$).
3. Составить обратный код ($[X]_{\text{обр}}$).
4. Составить дополнительный код ($[X]_{\text{доп}}$).
5. Выполнить операцию сложения $58_{10} + (-43_{10})$ в дополнительном коде 8-битного сумматора и доказать правильность результата обратным переводом в десятичную систему.

**Эталонное решение:**
1. Модуль $|-43| = 43_{10}$:
   - $43 = 32 + 8 + 2 + 1 = 2^5 + 2^3 + 2^1 + 2^0 = 00101011_2$.
2. Прямой код (знаковый бит 1, модуль в остальных 7 разрядах):
   - $[ -43 ]_{\text{пр}} = 10101011_2$.
3. Обратный код (знаковый бит 1, остальные биты инвертируются):
   - $[ -43 ]_{\text{обр}} = 11010100_2$.
4. Дополнительный код (обратный код плюс 1 к младшему разряду):
   - $[ -43 ]_{\text{доп}} = 11010100_2 + 1 = 11010101_2$.
5. Проверка сложением $58_{10} + (-43_{10})$:
   - Двоичное представление $58_{10}$: $58 = 32 + 16 + 8 + 2 = 00111010_2$.
   - В дополнительном коде $[+58]_{\text{доп}} = 00111010_2$.
   - Складываем на сумматоре:
```
    Переносы:   1 1 1 1   1      
       [+58]:   0 0 1 1 1 0 1 0
     + [-43]:   1 1 0 1 0 1 0 1
   ----------------------------
       Сумма: 1 0 0 0 0 1 1 1 1
```
   - Отбрасываем перенос за пределы 8 разрядов (он гасится отрицательным знаком в дополнительном коде).
   - В регистре остаётся: `00001111`.
   - Старший бит 0 (число положительное), значение: $2^3 + 2^2 + 2^1 + 2^0 = 8 + 4 + 2 + 1 = 15_{10}$.
   - Сравнение: $58 - 43 = 15_{10}$. Результат абсолютно корректен.

## 3. Эталонные решения домашнего / резервного дистанционного задания (`domashnee_zadanie.html`)

### Задание ДЗ-1. Двоичное вычитание через сложение в дополнительном коде
**Условие:**
Вычислить $A - B$ для $A = 74_{10}$, $B = 89_{10}$ в 8-разрядной сетке со знаком, используя дополнительный код.
**Решение:**
1. $A = 74_{10} = 64 + 8 + 2 = 01001010_2$.
2. $B = 89_{10} = 64 + 16 + 8 + 1 = 01011001_2$.
3. Формируем $[-B]_{\text{доп}}$:
   - Инвертируем биты $B$: `10100110`.
   - Прибавляем 1: `10100111`.
4. Складываем $A$ и $[-B]_{\text{доп}}$:
```
       [+74]:   0 1 0 0 1 0 1 0
     + [-89]:   1 0 1 0 0 1 1 1
   ----------------------------
       Сумма:   1 1 1 1 0 0 0 1
```
5. Старший бит 1 — результат отрицательный.
   Определяем величину модуля: инвертируем `11110001` $\to$ `00001110`, прибавляем 1 $\to$ `00001111` ($15_{10}$).
   Следовательно, результат равен $-15_{10}$.
   Проверка: $74 - 89 = -15$. Совпадает.

### Задание ДЗ-2. Анализ переполнения со знаком (флаг Overflow $OF$)
**Условие:**
Сложить два знаковых числа в 8 битах: $A = +95_{10}$ (`01011111`), $B = +65_{10}$ (`01000001`).
Показать, почему сумма в 8-разрядной сетке даёт отрицательное число, вычислить значение флага $OF$ и объяснить причину.
**Решение:**
```
    Переносы: 1 1 1 1 1 1 1  
          A:  0 1 0 1 1 1 1 1  (+95)
        + B:  0 1 0 0 0 0 0 1  (+65)
  ---------------------------------
      Сумма:  1 0 1 0 0 0 0 0  (-96 в int8)
```
- Сложение двух положительных чисел со знаковым битом `0` привело к появлению единицы в знаковом бите (`10100000`).
- Значение в дополнительном коде интерпретируется как: старший бит весит $-128$, остальные 0 $\implies -128 + 32 = -96$.
- В действительности $95 + 65 = 160$, что выходит за пределы диапазона 8-разрядных знаковых чисел $[-128 \dots +127]$.
- Перенос из 6-го разряда в 7-й равен $1$, а перенос из 7-го разряда наружу равен $0$.
- Флаг знакового переполнения $OF = C_6 \oplus C_7 = 1 \oplus 0 = 1$. Произошло переполнение со знаком (signed overflow).

## 4. Типовые ошибки студентов и методические рекомендации
1. **Смешение единиц информации и числового значения:**
   Студенты часто считают, что раз ячейка памяти равна 1 байту, в ней хранится только число до 255. Необходимо подчеркивать, что бит — это ёмкость ячейки (хранилища), а значение зависит исключительно от команды процессора, читающей эту ячейку (интерпретатора).
2. **Путаница переноса $CF$ и переполнения $OF$:**
   Студенты не различают перенос из разрядной сетки (актуален для беззнаковых чисел) и знаковое переполнение (когда сумма двух положительных чисел даёт отрицательное или наоборот).
3. **Ошибки в дополнительном коде:**
   Забывают прибавить $1$ к младшему разряду после инвертирования или инвертируют знаковый бит у положительного числа. Важно напоминать: положительные числа во всех трёх кодах (прямом, обратном, дополнительном) записываются одинаково.
