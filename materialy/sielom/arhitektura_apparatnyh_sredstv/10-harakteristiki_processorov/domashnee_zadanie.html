Разобранный образец: расчет ускорения и анализ архитектурного компромисса

Условие образца:

Программа трехмерного рендеринга имеет параллельную долю p = 90\% (0.90), а 10% времени тратится на последовательную загрузку геометрии сцены из файла. Рассчитайте ускорение по закону Амдала для 8-ядерного и 32-ядерного процессоров. Определите теоретический предел ускорения при бесконечном числе ядер.

Эталонное решение:

1. Формула закона Амдала: S(N) = frac{1}{(1 - p) + frac{p}{N}}

2. Расчет для N = 8:
S(8) = frac{1}{(1 - 0.90) + frac{0.90}{8}} = frac{1}{0.10 + 0.1125} = frac{1}{0.2125} ≈ 4.71× (ускорение в 4.71 раза при 8 ядрах).

3. Расчет для N = 32:
S(32) = frac{1}{0.10 + frac{0.90}{32}} = frac{1}{0.10 + 0.028125} = frac{1}{0.128125} ≈ 7.80× (ускорение в 7.80 раза при 32 ядрах).

4. Предельное ускорение (N → infty):
Smax = frac{1}{1 - p} = frac{1}{0.10} = 10.0×.

Архитектурный вывод: Даже при покупке 64-ядерного процессора ускорение составит лишь 8.89×, а превысить 10-кратный рубеж невозможно из-за 10% последовательного кода загрузки геометрии. Для дальнейшего ускорения необходимо оптимизировать именно дисковый ввод-вывод или переходить на быстрые NVMe-накопители.
