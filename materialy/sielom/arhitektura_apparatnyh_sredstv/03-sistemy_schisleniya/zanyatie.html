Системы счисления. Перевод чисел из одной системы счисления в другую

Индивидуальная практическая работа: выполнение двух разнотипных переводов чисел с обязательной обратной проверкой и развернутым математическим обоснованием каждого шага.

Данные обучающегося

Автосохранение: Ваши ответы автоматически сохраняются в браузере при вводе. Для сдачи работы воспользуйтесь кнопкой «Печать / Сохранить в PDF» внизу страницы.

Критерии оценивания работы (Всего: 4 балла)

Оценивание индивидуального продукта производится по открытым критериям:

Показатель Баллы Содержание критерия
Корректность перевода 0 – 2 Получены точные математические результаты двух переводов. (1 балл за каждый верно найденный результат).
Развернутое объяснение 0 – 1 В полях решения приведен детальный ход рассуждения: показаны все шаги деления на основание с остатками или расчет степенных весов разрядов.
Обратная проверка 0 – 1 Выполнен обратный перевод полученных результатов в исходную систему счисления, подтверждающий совпадение исходного значения.

Шкала перевода баллов: 4 балла — отлично («5»), 3 балла — хорошо («4»), 2 балла — удовлетворительно («3»), менее 2 баллов — не зачтено («2»).

Задание 1. Перевод десятичного числа в двоичную систему с обратной проверкой

Условие: Переведите десятичное число согласно вашему варианту в двоичную систему счисления методом деления на основание 2. Запишите полученный результат и проведите обратную проверку переводом полученного двоичного кода обратно в десятичную систему через развернутую форму.
Укажите все операции деления, частные и остатки снизу вверх. Демонстрационный образец: 45 / 2 = 22 (ост. 1), 22 / 2 = 11 (ост. 0)...
Запишите сумму произведений битов на веса разрядов (1, 2, 4, 8, 16...) и итоговую десятичную сумму. Демонстрационный образец: 1·32 + 0·16 + 1·8 + 1·4 + 0·2 + 1·1 = 45₁₀.

Задание 2. Перевод шестнадцатеричного числа в десятичную и двоичную системы с обратной проверкой

Условие: Переведите шестнадцатеричное число вашего варианта в десятичную систему (через развернутую форму) и в двоичную систему (через тетрады). Выполните обратную проверку полученного двоичного кода переводом в шестнадцатеричную форму группировкой тетрад.
Укажите развернутую форму записи с учетом числовых значений буквенных символов (A=10, B=11, C=12, D=13, E=14, F=15). Демонстрационный образец: 2D₁₆ = 2·16¹ + 13·16⁰ = 32 + 13 = 45₁₀.
Запишите двоичную тетраду (4 бита) для каждого шестнадцатеричного знака. Демонстрационный образец: 2₁₆ = 0010₂, D₁₆ = 1101₂. Итог: 00101101₂.
Разбейте полученный двоичный код на тетрады от младшего разряда и подтвердите исходный HEX-код. Демонстрационный образец: 0010 | 1101 → 0010₂ = 2₁₆, 1101₂ = 13₁₀ = D₁₆ → 2D₁₆.
