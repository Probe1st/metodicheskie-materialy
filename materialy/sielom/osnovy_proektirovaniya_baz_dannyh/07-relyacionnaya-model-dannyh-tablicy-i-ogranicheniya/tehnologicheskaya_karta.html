1) Реляционная революция Эдгара Кодда (1970).
2) Терминологический мост: отношение = таблица, кортеж = строка, атрибут = столбец, домен = тип данных + CHECK.

4) 4 свойства отношений: уникальность (PK), отсутствие порядка строк и столбцов, атомарность (1НФ).
5) Ограничения целостности: целостность сущности (Primary Key, NOT NULL), ссылочная целостность (Foreign Key, orphaned rows, правила RESTRICT, CASCADE, SET NULL), семантическая целостность (CHECK).
