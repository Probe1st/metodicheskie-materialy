Исходные данные практической модели

Отношение R(A, B, C, D, E, F)

Задана схема отношения R с универсальным множеством атрибутов U = {A, B, C, D, E, F} и следующим базовым множеством функциональных зависимостей F:

F = {
  A → BC,
  B → D,
  CD → E,
  E → F
}

Все зависимости отражают объективные семантические ограничения предметной области. Требуется провести строгий математический анализ схемы на основе аксиом Армстронга, алгоритма замыкания атрибутов и критериев канонического покрытия.

Задание 1. Вычисление замыкания множеств атрибутов X+

Используя алгоритм вычисления замыкания множества атрибутов относительно F, выполните пошаговую трассировку для указанных наборов. Обязательно указывайте применяемую функциональную зависимость на каждом шаге цикла расширения:

1.1. Вычисление замыкания {A}+

1.2. Вычисление замыкания {B}+

1.3. Вычисление замыкания {C, D}+

1.4. Вычисление замыкания {B, C}+

Задание 2. Определение потенциальных ключей отношения

Проведите классификацию атрибутов схемы по позициям в детерминантах и зависимых частях множества F (метод L-R-B-N). Докажите, какие атрибуты обязаны войти в состав ключа, и найдите ВСЕ потенциальные (кандидатные) ключи отношения R:

2.1. Классификация атрибутов (L, R, B, N)

2.2. Определение и доказательство потенциальных ключей

Задание 3. Минимальное покрытие ФЗ (Minimal Cover)

Примените трехшаговый алгоритм построения минимального (канонического) покрытия для исходного множества F: 1) расщепление правых частей (Singleton RHS); 2) устранение посторонних полей слева в составных детерминантах; 3) удаление избыточных зависимостей.
