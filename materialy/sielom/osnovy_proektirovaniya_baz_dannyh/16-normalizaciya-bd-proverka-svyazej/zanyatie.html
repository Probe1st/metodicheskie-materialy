Рабочий лист: Нормализация БД — проверка связей

Дисциплина «ОП.08 Основы проектирования баз данных» — Занятие №16 (СИЭУиП)
Выберите назначенный практический вариант:

Вариант 1. Проверка декомпозиции R(A, B, C) с ФЗ {A → B}

Исходная математическая спецификация:

Дано отношение R(A, B, C) с единственной нетривиальной функциональной зависимостью:

F = { A → B }

Сравниваются две схемы декомпозиции отношения R:

  • Схема декомпозиции №1: R₁(A, B) и R₂(A, C)
  • Схема декомпозиции №2: R₁(A, B) и R₃(B, C)

Вариант 2. База заказов маркетплейса (сохранение зависимости суммы)

Предметная область: Обработка заказов маркетплейса

Исходное отношение фиксирует строки клиентских заказов:

R(Номер_заказа, Артикул, Количество, Цена_за_ед, Сумма)

Бизнес-правила предметной области:

  • В заказе каждая позиция определяется составным ключом: {Номер_заказа, Артикул}.
  • Вычисляемая функциональная зависимость: {Количество, Цена_за_ед} → Сумма, где Сумма = Количество * Цена_за_ед.
  • В каталоге маркетплейса действует зависимость: Артикул → Цена_в_каталоге.

Вариант 3. Отношение «Преподаватели, Дисциплины, Учебники» (MVD и 4НФ)

Предметная область: Учебно-методическое обеспечение кафедры

Рассматривается отношение, связывающее преподавателей, читаемые курсы и рекомендуемые пособия:

R(Преподаватель, Дисциплина, Учебник)

Семантические ограничения предметной области:

  • Один преподаватель ведет несколько дисциплин (1:N).
  • Один преподаватель рекомендует список учебников (1:M).
  • Рекомендация учебника не зависит от того, какую конкретно дисциплину из своего списка читает преподаватель (независимые множественные списки).

Вариант 4. Высоконагруженная витрина данных (контролируемая денормализация)

Предметная область: Аналитическая витрина высоконагруженного ритейлера

В транзакционной базе данных (OLTP) действует нормализованная схема (3НФ):

Строки_чека(ID_позиции, ID_чека, ID_товара, Количество, Цена_продажи)

Товары(ID_товара, Название_товара, Артикул, ID_категории)

В сутки формируется 50 миллионов строк позиций чеков. Аналитический отдел ежеминутно запрашивает отчеты по выручке в разрезе Название_товара.
