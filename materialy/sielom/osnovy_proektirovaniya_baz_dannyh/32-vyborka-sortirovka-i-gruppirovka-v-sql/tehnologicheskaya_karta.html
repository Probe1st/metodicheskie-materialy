1. Цели и задачи занятия

Цель учебного занятия: Сформировать у обучающихся целостное понимание построения аналитических SQL-запросов: порядка логической обработки SELECT (FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT), применения агрегатных функций COUNT, SUM, AVG, MIN, MAX, группировки строк и фильтрации агрегированных групп; познакомить с оконной спецификацией OVER (PARTITION BY ... ORDER BY ...) и функциями ROW_NUMBER(), RANK(), DENSE_RANK().

Комплекс образовательных задач:

  • Обучающие: раскрыть логический порядок обработки предложений оператора SELECT реляционным оптимизатором; изучить правила применения агрегатных функций и их поведение со значениями NULL; усвоить синтаксические ограничения секций GROUP BY и HAVING; освоить вычисление рангов и номеров строк через оконные функции.
  • Развивающие: развивать аналитическое мышление при построении многомерных аналитических срезов данных, способность прогнозировать вычислительную сложность запросов и потребление памяти СУБД (Hash Aggregate vs Stream Aggregate).
  • Воспитательные: формировать культуру чистоты SQL-кода, строгость соблюдения стандартов реляционной алгебры и ответственность за достоверность формируемой бизнес-отчетности.

Осваиваемые компетенции (ФГОС СПО 09.02.07):

  • ОК 01 Выбирать способы решения задач профессиональной деятельности применительно к различным контекстам.
  • ОК 02 Использовать современные средства поиска, анализа и интерпретации информации.
  • ПК 1.3 Осуществлять разработку кода программного модуля на основе готовых спецификаций и схем баз данных.
  • ПК 2.4 Реализовывать запросы к базам данных на языке SQL для выборки, вставки, обновления и удаления записей.

Оснащение занятия и дидактические материалы:

  • Персональные компьютеры обучающихся с современным браузером (HTML5, LocalStorage).
  • Автономный интерактивный веб-комплект учебных материалов: интерактивный рабочий лист (zanyatie.html), теоретический конспект (lekciya.html), слайдовая презентация (prezentaciya.html), методическое руководство (metodicheskiy_material.html), критериальная рубрика (.rubrika.md), резервное домашнее задание (domashnee_zadanie.html).
  • Мультимедийный проектор, демонстрационный экран, интерактивная доска/терминал СУБД.

1. Организационный момент и мотивация
80 мин: 0–5 (5 мин)
60 мин: 0–3 (3 мин) 		Организация учебного внимания группы, фиксация явки, создание проблемной ситуации. Приветствует студентов, фиксирует присутствующих. 2. Актуализация опорных знаний
80 мин: 5–12 (7 мин)
60 мин: 3–8 (5 мин) 		Повторение синтаксиса базового SELECT, фильтрации WHERE и сортировки ORDER BY, выявление пробелов. Проводит фронтальный экспресс-опрос: назначение ключевых слов SELECT, FROM, WHERE; работа логических операторов AND/OR/NOT; влияние пропущенных значений NULL на предикаты сравнения. Отвечают на вопросы преподавателя, вспоминают трехзначную логику SQL (TRUE, FALSE, UNKNOWN), приводят примеры фильтрации строк.
3. Изложение нового теоретического материала
80 мин: 12–48 (36 мин)
60 мин: 8–34 (26 мин) 		Формирование фундаментальных понятий: логический конвейер SELECT, агрегатные функции, GROUP BY, HAVING, ROLLUP/CUBE, базовые оконные функции OVER(PARTITION BY). Демонстрирует презентацию prezentaciya.html (слайды 2–14). Подробно разбирает цепочку выполнения: FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT. Объясняет семантику COUNT(*) против COUNT(col), поведение AVG при NULL. Показывает разницу между WHERE и HAVING. Вводит оконные функции ROW_NUMBER(), RANK(), DENSE_RANK(). Воспринимают учебный материал, зарисовывают в конспекты блок-схему логического конвейера, фиксируют «золотое правило» GROUP BY и сравнительную таблицу функций ранжирования. Задают уточняющие вопросы.
4. Практическая демонстрация сквозного кейса
80 мин: 48–58 (10 мин)
60 мин: 34–42 (8 мин) 		Наглядная иллюстрация работы агрегатных запросов в реальной СУБД, демонстрация плана выполнения. В терминале СУБД/pgAdmin исполняет демонстрационный запрос с группировкой, фильтрацией HAVING и оконным ранжированием. Показывает план запроса (EXPLAIN) и появление узла HashAggregate. Следят за выполнением демонстрации на проекторе, сопоставляют полученный результирующий набор с теоретическими ожиданиями.
5. Закрепление: практикум в zanyatie.html
80 мин: 58–74 (16 мин)
60 мин: 42–56 (14 мин) 		Отработка навыков составления аналитических SQL-запросов по индивидуальным дифференцированным вариантам. Организует работу с интерактивным рабочим листом zanyatie.html. Распределяет студентов по 4 прикладным вариантам (ритейл, медицина, колледж, автопарк). Консультирует, контролирует самостоятельность, проверяет применение HAVING и оконных функций. Открывают в браузере zanyatie.html, заполняют ФИО и группу, решают задачи своего варианта, пишут SQL-запросы с GROUP BY, HAVING, агрегацией и оконным ранжированием, сохраняют ответы в LocalStorage.
