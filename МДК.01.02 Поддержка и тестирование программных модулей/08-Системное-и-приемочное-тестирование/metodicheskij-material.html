Занятие 08. Системное и приёмочное тестирование — методический материал

Ваш результат

Разграничивает задачи системного и приёмочного тестирования в проекте.

Тема блока: Уровни тестирования. Ключевые слова: системное тестирование, приёмка, требования, сценарий.

Методический разбор

Системная проверка наблюдает связанный сценарий целиком, а приёмочная — подтверждает согласованное с заказчиком ожидание. Одинаковый запуск может дать данные для обеих целей, но критерии и формулировки результата различаются.

Понятия для работы

Системный сценарий
Последовательность действий через взаимодействующие части программы.
Критерий приёмки
Согласованное условие, по которому принимается результат пользовательского сценария.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

def create_confirmation(guest: str, nights: int) -> dict[str, object]:
    if not guest.strip() or nights < 1:
        raise ValueError("Неполные данные бронирования")
    return {"guest": guest, "nights": nights, "status": "подтверждено"}

test_booking_service.py

from booking_service import create_confirmation


def test_confirmation_contains_user_visible_status() -> None:
    confirmation = create_confirmation("Ирина", 2)
    assert confirmation["status"] == "подтверждено"
    assert confirmation["nights"] == 2

Практический маршрут

  1. Составьте сквозной сценарий создания бронирования.
  2. Отметьте точки, в которых меняется состояние данных.
  3. Добавьте критерий приёмки, выраженный наблюдаемым результатом.
