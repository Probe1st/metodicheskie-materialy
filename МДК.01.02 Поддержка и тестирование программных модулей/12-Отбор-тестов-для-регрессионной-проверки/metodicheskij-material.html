Занятие 12. Отбор тестов для регрессионной проверки — методический материал

Ваш результат

Формирует приоритетный набор регрессионных тестов на основе рисков и связей требований.

Тема блока: Регрессия. Ключевые слова: регрессионный набор, приоритизация, трассируемость, критичность.

Методический разбор

Отбор регрессионных проверок делает решение прозрачным: вы связываете тест с изменением, риском и стоимостью запуска. Приоритет не означает, что остальные проверки потеряли смысл; он определяет порядок при ограниченном времени.

Понятия для работы

Трассируемость
Явная связь между требованием, изменением, риском и проверкой.
Приоритизация
Выбор порядка выполнения проверок по согласованному признаку.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

def select_checks(changes: set[str], catalogue: dict[str, set[str]]) -> list[str]:
    return [name for name, covered in catalogue.items() if changes & covered]

test_booking_service.py

from booking_service import select_checks


def test_changed_promo_selects_only_related_checks() -> None:
    catalogue = {"promo": {"promo"}, "availability": {"rooms"}, "total": {"promo", "rate"}}
    assert select_checks({"promo"}, catalogue) == ["promo", "total"]

  2. Почему отсутствие связи не доказывает, что сценарий безопасен для исключения?

Практический маршрут

  1. Создайте каталог из пяти тестов и связанных правил.
  2. Смоделируйте изменение одного правила и получите первоначальный отбор.
  3. Расположите отобранные проверки по риску и объясните порядок.
