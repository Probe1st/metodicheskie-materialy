Занятие 26. Средства подготовки программной документации — методический материал

Ваш результат

Сравнивает текстовые редакторы, системы разметки и генераторы документации для учебного проекта.

Тема блока: Средства и технологии документации. Ключевые слова: редактор, разметка, генератор, шаблон.

Методический разбор

Инструмент подготовки документации выбирают от исходного материала и способа обновления. Текстовая разметка удобна, когда структура и ссылки должны быть видимы в исходнике; генератор полезен, когда повторяющиеся сведения получают из кода или данных.

Понятия для работы

Markdown
Текстовая разметка, в которой заголовки, списки и ссылки остаются читаемыми в исходном виде.
Шаблон
Структура документа с местами для данных, которые подставляются при создании версии.

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

def markdown_heading(text: str, level: int = 2) -> str:
    if level < 1:
        raise ValueError("Уровень заголовка должен быть положительным")
    return f"{'#' * level} {text}

test_booking_service.py

from booking_service import markdown_heading


def test_markdown_heading_keeps_document_title() -> None:
