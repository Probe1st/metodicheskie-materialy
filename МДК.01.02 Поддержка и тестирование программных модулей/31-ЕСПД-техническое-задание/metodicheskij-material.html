Тема блока: Документирование по ЕСПД. Ключевые слова: техническое задание, требование, критерий приёмки, ЕСПД.

Методический разбор

Техническое задание превращает намерение в проверяемые требования. Хорошая формулировка даёт идентификатор, условие, ожидаемое поведение и способ проверить результат; она не подменяет критерий общим обещанием качества.

Понятия для работы

Требование
Согласованное условие к продукту, которое можно связать с проверкой результата.
Критерий приёмки
Наблюдаемое условие, подтверждающее выполнение конкретного требования.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

def acceptance_case(requirement_id: str, observed: str, expected: str) -> bool:
    if not requirement_id.startswith("REQ-"):
        raise ValueError("Нужен идентификатор требования")
    return observed == expected

test_booking_service.py

from booking_service import acceptance_case


def test_requirement_case_compares_observed_result() -> None:
    assert acceptance_case("REQ-BOOK-01", "подтверждено", "подтверждено")
