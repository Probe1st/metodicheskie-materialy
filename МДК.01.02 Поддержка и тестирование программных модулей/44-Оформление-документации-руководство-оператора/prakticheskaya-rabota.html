Тема блока: Оформление документации. Ключевые слова: руководство оператора, пошаговая инструкция, сценарий, сообщение об ошибке.

Подготовка

Руководство оператора строится вокруг цели пользователя. Каждый шаг должен указывать действие, данные и видимый результат; ожидаемая ошибка получает отдельную ветвь с безопасным следующим шагом.

Команды подготовки

python -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pytest -q

Стартовый фрагмент сервиса бронирования

Сохраните фрагмент в booking_service.py. Он синтаксически завершён; тесты добавляйте отдельным файлом.

booking_service.py

def create_booking_message(guest: str, room: str) -> str:
    if not guest or not room:
        return "Заполните имя гостя и номер"
    return f"Бронирование для {guest} в номере {room} подтверждено

Обязательная работа

  1. Опишите подготовку и основной сценарий создания бронирования.
  2. Для каждого шага укажите действие, данные и видимый результат.
  3. Добавьте ветвь инструкции для отсутствующего номера и проверьте её на соответствие сообщению программы.

Усложнение

Прочитайте инструкцию как новый оператор: удалите внутренние термины, которые не объясняют следующее действие.

Ожидаемые артефакты

  • руководство оператора
  • скрин-схема или макет экрана
  • ветвь ошибки

Чек-лист сдачи

  • исходные файлы запускаются командой python -m pytest -q
  • ожидаемые и фактические результаты не смешаны
  • каждый тест или раздел связан с конкретным правилом
  • изменения отражены в истории или краткой заметке

Критерии оценки результата

  • правила темы выражены проверяемыми входами, действиями и результатами
  • артефакты полны и согласованы между собой
  • выводы опираются на наблюдение, а не на предположение
