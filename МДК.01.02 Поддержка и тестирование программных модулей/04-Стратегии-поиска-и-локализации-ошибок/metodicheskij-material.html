Занятие 04. Стратегии поиска и локализации ошибок — методический материал

Ваш результат

Выбирает стратегию отладки и обосновывает порядок локализации дефекта.

Тема блока: Ошибки и отладка. Ключевые слова: отладка, трассировка, точка останова, локализация.

Методический разбор

Локализуйте дефект небольшими наблюдаемыми шагами: сначала добейтесь воспроизведения, затем сузьте участок данных и ветвей. Лог фиксирует выбранные факты, а интерактивный отладчик pdb полезен для осмотра состояния в конкретной точке.

Понятия для работы

Воспроизведение
Повторяемый запуск с теми же входными условиями и наблюдаемым расхождением.
Трассировка
Запись значимых переходов и данных, помогающая сузить область поиска.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

import logging

logger = logging.getLogger(__name__)


def normalize_guest_count(value: str) -> int:
    count = int(value)
    logger.debug("Преобразовано количество гостей: %s", count)
    if count < 1:
        raise ValueError("Нужен хотя бы один гость")
    return count

test_booking_service.py

import logging
import pytest

from booking_service import normalize_guest_count


def test_debug_record_contains_normalized_value(caplog: pytest.LogCaptureFixture) -> None:
    caplog.set_level(logging.DEBUG)
    assert normalize_guest_count("2") == 2
    assert "2" in caplog.text


def test_zero_guests_is_rejected() -> None:
    with pytest.raises(ValueError):
        normalize_guest_count("0")

Практический маршрут

  1. Воспроизведите неверное значение количества гостей одним тестом.
  2. Добавьте журналирование только в точке перехода между строкой и числом.
  3. Запишите гипотезу, наблюдение и результат её проверки.
