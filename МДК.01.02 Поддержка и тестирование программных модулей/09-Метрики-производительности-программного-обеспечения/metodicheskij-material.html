Занятие 09. Метрики производительности программного обеспечения — методический материал

Ваш результат

Выбирает метрики производительности для заданного пользовательского сценария.

Тема блока: Производительность. Ключевые слова: время отклика, пропускная способность, нагрузка, метрика.

Методический разбор

Производительность измеряют в контексте выбранного сценария и окружения. Время выполнения само по себе не является выводом: фиксируйте вход, способ измерения и то, с чем Вы будете сравнивать результат.

Понятия для работы

Время отклика
Интервал, измеренный для конкретного действия от его начала до результата.
Базовая линия
Зафиксированное измерение, с которым Вы сравниваете последующие запуски.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

from time import perf_counter


def measure(action) -> tuple[object, float]:
    started = perf_counter()
    result = action()
    return result, perf_counter() - started

test_booking_service.py

from booking_service import measure


def test_measure_returns_action_result_and_nonnegative_duration() -> None:
    result, elapsed = measure(lambda: "готово")
    assert result == "готово"
    assert elapsed >= 0

Проверьте понимание

  1. Какие входные данные и условия окружения Вы запишете рядом с измерением?
  2. Почему нельзя переносить число из одного запуска на другой без описания сценария?

Практический маршрут

  1. Выберите действие сервиса, которое измерите.
  2. Сделайте несколько запусков с одинаковыми входами и сохраните результаты.
  3. Сформулируйте осторожный вывод, не выходящий за границы измеренного сценария.

Рефлексия

Запишите, какое предположение Вы проверили, какой результат наблюдали и какое следующее условие стоит исследовать. Отделите факт запуска от своего объяснения причины.
