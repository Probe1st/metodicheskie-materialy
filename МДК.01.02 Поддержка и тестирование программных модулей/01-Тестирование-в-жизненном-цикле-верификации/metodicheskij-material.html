Занятие 01. Тестирование в жизненном цикле верификации — методический материал

Ваш результат

Объясняет место тестирования среди работ по верификации программного обеспечения.

Тема блока: Тестирование в верификации. Ключевые слова: верификация, валидация, жизненный цикл, качество.

Методический разбор

Верификация связывает результат работы с заранее сформулированным ожиданием: для каждой проверки вы записываете вход, наблюдаемое поведение и критерий. Валидацию рассматривайте отдельно: она отвечает на вопрос о полезности результата в предполагаемом сценарии.

Понятия для работы

Верификационное утверждение
Проверяемая связь между условием и ожидаемым результатом.
Наблюдаемый результат
Значение, сообщение или состояние, которое можно сравнить с ожиданием.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

def availability_label(free_rooms: int) -> str:
    if free_rooms < 0:
        raise ValueError("Количество мест не может быть отрицательным")
    return "доступно" if free_rooms else "нет мест

test_booking_service.py

import pytest

from booking_service import availability_label


def test_empty_stock_is_reported_to_client() -> None:
    assert availability_label(0) == "нет мест"


def test_negative_stock_breaks_contract() -> None:
    with pytest.raises(ValueError):
        availability_label(-1)

Практический маршрут

  1. Запишите для функции availability_label триаду: вход, действие, ожидаемый результат.
  2. Добавьте случай с положительным остатком и объясните, какое правило он подтверждает.
  3. Сформулируйте одно условие, которое пример пока не проверяет, и добавьте тест.
