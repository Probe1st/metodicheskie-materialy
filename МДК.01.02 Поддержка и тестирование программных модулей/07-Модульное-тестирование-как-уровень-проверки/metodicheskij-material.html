Занятие 07. Модульное тестирование как уровень проверки — методический материал

Ваш результат

Определяет границы модуля и критерии его изолированной проверки.

Тема блока: Уровни тестирования. Ключевые слова: модуль, изоляция, заглушка, юнит-тест.

Методический разбор

Модульный тест проверяет маленькую договорённость модуля при контролируемых зависимостях. Граница модуля определяется тем, что Вы хотите наблюдать напрямую, а не размером файла.

Понятия для работы

Изоляция
Управление зависимостями, чтобы результат проверки зависел от выбранного поведения.
Фикстура
Повторно используемая подготовка состояния теста в pytest.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

def remaining_rooms(capacity: int, confirmed: int) -> int:
    if confirmed > capacity:
        raise ValueError("Подтверждений больше вместимости")
    return capacity - confirmed

test_booking_service.py

import pytest

from booking_service import remaining_rooms


@pytest.fixture
def standard_capacity() -> int:
    return 4


def test_remaining_rooms_uses_prepared_capacity(standard_capacity: int) -> None:
    assert remaining_rooms(standard_capacity, 1) == 3

  2. Когда тесту нужна подмена зависимости вместо настоящего обращения к ней?

Практический маршрут

  1. Разделите один тест на подготовку, действие и проверку результата.
  2. Вынесите общую вместимость в фикстуру.
  3. Добавьте проверку недопустимого числа подтверждений.
