Занятие 10. Планирование нагрузочного тестирования — методический материал

Ваш результат

Составляет план нагрузочного эксперимента с профилем пользователей и критериями результата.

Тема блока: Производительность. Ключевые слова: нагрузочное тестирование, профиль нагрузки, пиковая нагрузка, SLA.

Методический разбор

План нагрузочного эксперимента связывает профиль действий, наблюдаемые метрики и условие остановки. Сначала создайте небольшой воспроизводимый профиль, затем меняйте только один параметр за запуск.

Понятия для работы

Профиль нагрузки
Описание количества и последовательности действий, которые воспроизводит эксперимент.
Пропускная способность
Количество завершённых действий за выбранный интервал при явно описанных условиях.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

from time import perf_counter


def run_profile(action, repetitions: int) -> tuple[int, float]:
    started = perf_counter()
    completed = sum(action() == "ok" for _ in range(repetitions))
    return completed, perf_counter() - started

test_booking_service.py

from booking_service import run_profile


def test_profile_counts_completed_actions() -> None:
    completed, elapsed = run_profile(lambda: "ok", 3)
    assert completed == 3
    assert elapsed >= 0

Практический маршрут

  1. Опишите профиль из трёх одинаковых действий бронирования.
  2. Выберите метрику завершённых действий и способ её записи.
  3. Добавьте профиль, в котором одно действие возвращает иной результат.
