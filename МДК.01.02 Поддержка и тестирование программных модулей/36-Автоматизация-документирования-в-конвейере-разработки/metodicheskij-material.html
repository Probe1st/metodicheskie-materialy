Занятие 36. Автоматизация документирования в конвейере разработки — методический материал

Ваш результат

Объясняет, как проверка и публикация документации встраиваются в конвейер разработки.

Тема блока: Автоматизация документации. Ключевые слова: CI/CD, сборка, публикация, проверка ссылок.

Методический разбор

В конвейере документация проходит те же проверяемые границы, что и код: исходник, сборка, проверка структуры и публикация. Автоматизация полезна, когда её результат можно повторить из тех же исходных данных и увидеть причину остановки.

Понятия для работы

Конвейер
Последовательность повторяемых шагов от исходника к проверенному результату.
Проверка ссылок
Контроль того, что внутренние ссылки указывают на существующие цели в публикации.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

def broken_internal_links(links: list[str], pages: set[str]) -> list[str]:
    return [link for link in links if link.startswith("#") and link[1:] not in pages]

test_booking_service.py

from booking_service import broken_internal_links


def test_checker_reports_missing_anchor() -> None:
    assert broken_internal_links(["#setup", "#missing"], {"setup"}) == ["#missing"]
