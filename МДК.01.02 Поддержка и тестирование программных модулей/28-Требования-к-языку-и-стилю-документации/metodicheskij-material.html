Занятие 28. Требования к языку и стилю документации — методический материал

Ваш результат

Редактирует формулировки так, чтобы требования и инструкции были однозначными.

Тема блока: Средства и технологии документации. Ключевые слова: однозначность, терминология, стиль, инструкция.

Методический разбор

Ясная документация называет субъект, действие, условие и ожидаемый результат. Проверяйте неоднозначные слова: «быстро», «корректно» и «при необходимости» не дают читателю проверяемого действия без дополнительного контекста.

Понятия для работы

Однозначность
Возможность понять условие и действие одинаково при повторном чтении.
Терминология
Согласованный набор слов, которым одинаковые сущности названы во всех разделах.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

AMBIGUOUS = {"быстро", "корректно", "при необходимости"}


def ambiguous_words(text: str) -> set[str]:
    lowered = text.casefold()
    return {word for word in AMBIGUOUS if word in lowered}

test_booking_service.py

from booking_service import ambiguous_words


def test_review_finds_ambiguous_instruction() -> None:
    assert ambiguous_words("Быстро подтвердите бронирование") == {"быстро"}

Проверьте понимание

  1. Как замените слово «корректно» наблюдаемым критерием результата?
  2. Каким одним термином Вы назовёте подтверждённую запись во всех разделах?

Практический маршрут

  1. Найдите неявное условие в короткой инструкции.
  2. Перепишите его в форме «если — то — ожидаемый результат».
  3. Составьте мини-глоссарий из пяти терминов сервиса.
