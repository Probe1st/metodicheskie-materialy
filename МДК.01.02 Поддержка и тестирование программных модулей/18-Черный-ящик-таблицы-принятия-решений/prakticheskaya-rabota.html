Занятие 18. Чёрный ящик: таблицы принятия решений — практическая работа

Ваш результат

Преобразует бизнес-правила в таблицу решений и тестовые случаи.

Тема блока: Чёрный ящик. Ключевые слова: таблица решений, бизнес-правило, комбинация условий, тест-кейс.

Подготовка

Используйте правило скидки как спецификацию. До написания тестов составьте таблицу решений, где строки — комбинации условий, а столбец — действие.

Команды подготовки

python -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pytest -q

Стартовый фрагмент сервиса бронирования

Сохраните фрагмент в booking_service.py. Он синтаксически завершён; тесты добавляйте отдельным файлом.

booking_service.py

def discount_percent(has_code: bool, is_member: bool) -> int:
    if has_code and is_member:
        return 15
    if has_code or is_member:
        return 5
    return 0

Обязательная работа

  1. Заполните все комбинации has_code и is_member в таблице решений.
  2. Назначьте ожидаемую скидку каждой строке, затем перенесите строки в параметризацию pytest.
  3. Добавьте правило приоритета, если два условия ведут к разным возможным действиям.

Усложнение

Сформулируйте новую комбинацию «код просрочен» и покажите, какие строки таблицы и тесты должны измениться.

Ожидаемые артефакты

  • таблица решений
  • параметризованные тесты
  • правило приоритета

Чек-лист сдачи

  • исходные файлы запускаются командой python -m pytest -q
  • ожидаемые и фактические результаты не смешаны
  • каждый тест или раздел связан с конкретным правилом
  • изменения отражены в истории или краткой заметке

Критерии оценки результата

  • правила темы выражены проверяемыми входами, действиями и результатами
  • артефакты полны и согласованы между собой
  • выводы опираются на наблюдение, а не на предположение

Источники
