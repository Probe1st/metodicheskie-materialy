Занятие 05. Статические методы тестирования — методический материал

Ваш результат

Вы сможете: применить обзор и анализ артефактов для выявления дефектов до запуска программы.

Тема блока: Методы тестирования. Ключевые слова: статический анализ, инспекция, обзор, код-ревью.

Методический разбор

Статическая проверка рассматривает артефакт без выполнения основного сценария. Начинайте с проверяемого правила: структура, термин, обязательный раздел или связь между требованием и тестом. Такой обзор не заменяет запуск, но уменьшает число неясностей до него.

Понятия для работы

Инспекция
Последовательная проверка артефакта по заранее согласованным вопросам.
Чек-лист обзора
Короткий набор критериев, по которому вы фиксируете найденные несоответствия.

Выполнимый пример Python и pytest

Создайте два файла с указанными именами, затем запустите проверку командой python -m pytest -q. Сначала прочитайте ожидаемый результат теста и только затем меняйте код.

booking_service.py

import ast


def has_booking_function(source: str) -> bool:
    tree = ast.parse(source)
    return any(
        isinstance(node, ast.FunctionDef) and node.name == "create_booking"
        for node in tree.body
    )

test_booking_service.py

from booking_service import has_booking_function


def test_review_rule_requires_named_operation() -> None:
    source = "def create_booking():\n    return None\n"
    assert has_booking_function(source)


def test_review_rule_rejects_unrelated_name() -> None:
    assert not has_booking_function("def reserve():\n    return None\n")

Практический маршрут

  1. Составьте чек-лист из четырёх вопросов к модулю бронирования.
  2. Автоматизируйте один структурный вопрос с помощью ast.
  3. Зафиксируйте замечание так, чтобы другой участник мог его воспроизвести.
