Занятие 23. Интеграционное тестирование: потоки данных — практическая работа

Ваш результат

Вы сможете: спроектировать интеграционные сценарии для передачи данных между компонентами.

Тема блока: Интеграционное тестирование. Ключевые слова: поток данных, сериализация, API, сценарий.

Подготовка

Проверьте поток данных как последовательность преобразований. На каждом переходе сохраняйте тип и смысл полей, а тестом наблюдайте конечный объект, а не только отдельную функцию кодирования.

Команды подготовки

python -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pytest -q

Стартовый фрагмент сервиса бронирования

Сохраните фрагмент в booking_service.py. Он синтаксически завершён; тесты добавляйте отдельным файлом.

booking_service.py

import json


def encode_confirmation(reference: str, nights: int) -> str:
    return json.dumps({"reference": reference, "nights": nights}, ensure_ascii=False)


def decode_confirmation(payload: str) -> dict[str, object]:
    return json.loads(payload)

Обязательная работа

  1. Определите исходный объект, сериализованную форму и объект после декодирования.
  2. Напишите интеграционный тест, который проходит оба преобразования и сравнивает поля.
  3. Добавьте случай с отсутствующим ожидаемым полем и зафиксируйте место обнаружения несоответствия.

Усложнение

Покажите в отчёте один снимок каждого состояния данных, не включая чувствительные сведения о госте.

Ожидаемые артефакты

  • модуль сериализации
  • сквозной тест потока
  • таблица состояний данных

Чек-лист сдачи

  • исходные файлы запускаются командой python -m pytest -q
  • ожидаемые и фактические результаты не смешаны
  • каждый тест или раздел связан с конкретным правилом
  • изменения отражены в истории или краткой заметке

Критерии оценки результата

  • правила темы выражены проверяемыми входами, действиями и результатами
  • артефакты полны и согласованы между собой
  • выводы опираются на наблюдение, а не на предположение
