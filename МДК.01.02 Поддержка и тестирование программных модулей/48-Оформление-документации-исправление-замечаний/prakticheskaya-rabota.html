Занятие 48. Оформление документации: исправление замечаний — практическая работа

Ваш результат

Вы сможете: внести замечания рецензента без нарушения согласованности связанных документов.

Тема блока: Оформление документации. Ключевые слова: замечание, исправление, согласование, версия документа.

Подготовка

Исправление замечаний — это управляемое изменение: сначала подтвердите замечание, затем обновите связанные места, сохраните историю и повторно проверьте критерий. Не закрывайте замечание, пока новая формулировка не согласована с требованиями и испытаниями.

Команды подготовки

python -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pytest -q

Стартовый фрагмент сервиса бронирования

Сохраните фрагмент в booking_service.py. Он синтаксически завершён; тесты добавляйте отдельным файлом.

booking_service.py

def apply_revision(document: str, old: str, new: str) -> str:
    if old not in document:
        raise ValueError("Исходная формулировка не найдена")
    return document.replace(old, new, 1)

Обязательная работа

  1. Выберите замечание из предыдущей практики и свяжите его с конкретным разделом.
  2. Внесите исправление и найдите документы, где повторяется затронутый факт.
  3. Добавьте запись истории изменений и выполните повторную проверку критерия замечания.

Усложнение

Покажите разницу до и после правки и объясните, почему она не ввела противоречие в программу испытаний или инструкцию.

Ожидаемые артефакты

  • исправленный документ
  • история изменений
  • повторная проверка замечаний

Чек-лист сдачи

  • исходные файлы запускаются командой python -m pytest -q
  • ожидаемые и фактические результаты не смешаны
  • каждый тест или раздел связан с конкретным правилом
  • изменения отражены в истории или краткой заметке

Критерии оценки результата

  • правила темы выражены проверяемыми входами, действиями и результатами
  • артефакты полны и согласованы между собой
  • выводы опираются на наблюдение, а не на предположение
