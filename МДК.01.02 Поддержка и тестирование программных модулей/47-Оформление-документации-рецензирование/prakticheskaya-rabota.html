Занятие 47. Оформление документации: рецензирование — практическая работа

Ваш результат

Проводит рецензирование документа по критериям полноты, точности и согласованности.

Тема блока: Оформление документации. Ключевые слова: рецензирование, полнота, точность, согласованность.

Подготовка

Рецензирование проверяет полноту, точность и согласованность текста с другими документами. Замечание должно указывать место, наблюдаемую проблему, критерий и желаемый результат, а не оценивать автора документа.

Команды подготовки

python -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pytest -q

Стартовый фрагмент сервиса бронирования

Сохраните фрагмент в booking_service.py. Он синтаксически завершён; тесты добавляйте отдельным файлом.

booking_service.py

def review_comment(section: str, issue: str, criterion: str) -> str:
    return f"{section}: {issue}. Критерий: {criterion}.

Обязательная работа

  1. Составьте чек-лист полноты, точности и согласованности для технического задания и инструкции.
  2. Проведите рецензирование одного раздела и сформулируйте не менее трёх проверяемых замечаний.
  3. Сверьте каждое замечание с источником: требованием, программой или другим документом комплекта.

Усложнение

Отделите дефект документа от предложения улучшения: первое должно иметь нарушенный критерий, второе — пометку как вариант.

Ожидаемые артефакты

  • чек-лист рецензирования
  • карточки замечаний
  • ссылки на критерии

Чек-лист сдачи

  • исходные файлы запускаются командой python -m pytest -q
  • ожидаемые и фактические результаты не смешаны
  • каждый тест или раздел связан с конкретным правилом
  • изменения отражены в истории или краткой заметке

Критерии оценки результата

  • правила темы выражены проверяемыми входами, действиями и результатами
  • артефакты полны и согласованы между собой
  • выводы опираются на наблюдение, а не на предположение
