# Комплект материалов МДК.01.02 «Поддержка и тестирование программных модулей»

## Назначение

Подготовить самостоятельный комплект материалов для публикации в статическом хостинге. Содержание рассчитано на последовательное освоение тестирования, отладки и документирования программных модулей на Python 3.12 и pytest.

## Границы

Источник нагрузки — рабочая программа ПМ.01, МДК.01.02. В комплект входят 98 контактных часов: 49 отдельных занятий по 2 академических часа. Консультация, экзамен и 6 часов самостоятельной работы не оформляются как занятия.

Темы:

- отладка и тестирование ПО — 24 занятия: 12 теоретических и 12 практических;
- документирование — 25 занятий: 15 теоретических и 10 практических.

## Дерево публикации

Корневая папка: `МДК.01.02 Поддержка и тестирование программных модулей`.

Внутри — 49 папок с префиксом двухзначного номера и кратким названием. Например:

```text
01-Тестирование-в-верификации/
  metodicheskij-material.html
  prezentaciya.pdf
  prakticheskie-zadaniya.html
  domashnee-zadanie.html
27-Белый-ящик-ветви-и-пути/
  prakticheskaya-rabota.html
  prakticheskie-zadaniya.html
  domashnee-zadanie.html
```

Каждая теоретическая папка содержит методический материал HTML, PDF-презентацию, практические задания HTML и домашнее задание HTML. Каждая практическая папка содержит практическую работу HTML, практические задания HTML и домашнее задание HTML. У практических занятий нет лекционного HTML и PDF-презентации.

## Конструкция занятия

Каждый HTML является автономной веб-страницей без внешних зависимостей: семантическая разметка, встроенные стили для чтения с экрана и печати, оглавление, проверяемые результаты и критерии самопроверки.

Теоретический материал:

1. ожидаемые результаты и входные знания;
2. объяснение понятий на примерах Python/pytest;
3. короткие проверки понимания;
4. практические задания по нарастающей сложности;
5. рефлексия и самостоятельная работа.

Практическая работа:

1. цель, входные данные, ПО и подготовка;
2. воспроизводимый сценарий выполнения;
3. исходные данные или фрагменты кода;
4. обязательные задания и усложнение;
5. формат сдачи, чек-лист и критерии оценивания.

Домашние задания продолжают тему без дублирования аудиторной работы; содержат критерии результата и формат сдачи.

## Практический сквозной контекст

Практики используют небольшой учебный проект «Сервис бронирования»: расчёт стоимости, промокоды, доступность ресурсов, уведомления и журналирование. Это даёт реалистичные зависимости для unit-, integration-, regression- и performance-тестирования, а также объекты для технической документации. Код рассчитан на Python 3.12, pytest и стандартную библиотеку; внешний доступ к сервисам не обязателен.

## Актуальность и источники

Содержательные утверждения опираются на первичные источники и актуальные руководства: ISO/IEC/IEEE 29119, ISTQB CTFL v4.0.1, документацию Python 3.12, pytest, Playwright и GitHub Docs. Для документации дополнительно используются действующие ГОСТ 19 и ГОСТ 34, проверенные по официальным каталогам Росстандарта. В каждом материале приводится краткий список ссылок на использованные источники.

## PDF-презентации

Презентации — компактные PDF с заголовком темы, схемами, примерами кода, вопросами для самопроверки и ссылками на соответствующий HTML. Они повторяют логику методического материала, не подменяя его.

## Контроль качества

Перед передачей:

- проверить наличие 49 папок и обязательных файлов по типу занятия;
- убедиться, что все HTML открываются локально без сети и содержат только студенческое обращение;
- проверить PDF как валидные, непустые документы с извлекаемым текстом;
- проверить соответствие суммарной нагрузки: 49 занятий × 2 академических часа.
