# Комплект материалов по обеспечению качества Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Создать статически развёртываемую рабочую программу и полный набор студентческих материалов для 11 занятий.

**Architecture:** Один временный Python-генератор создаёт единообразные автономные HTML-документы из структурированных данных уроков. Встроенный Chromium через браузерную автоматизацию печатает HTML-презентации в PDF; временный генератор и промежуточные HTML презентаций удаляются после проверки.

**Tech Stack:** HTML5, CSS, JavaScript, Python 3, встроенный Chromium/Puppeteer.

## Global Constraints

- Корневой каталог: `Обеспечение качества функционирования компьютерных систем`.
- Создать `00_Рабочая_программа.html` и по пять файлов для каждого из 11 занятий.
- `Методический_материал.html`, `Домашнее_задание.html`, `Практическая_работа.html`, `Практические_задания.html` должны быть автономными HTML.
- `Презентация.pdf` должна быть корректным PDF с текстом на русском языке.
- Занятия 3, 5, 7, 9, 11 — практические и не содержат лекционного изложения.
- В документах нет слов о длительности занятия, «паре», колледже или распределении времени.
- Во всех материалах обращение направлено к студенту во втором лице множественного числа.
- Сквозной кейс — Python-сервис заказов; автоматизация на pytest.
- Источники: ISO/IEC 25010:2023, OWASP Top 10:2025, Python docs, pytest docs.

### Task 1: Создать генератор автономных материалов

**Files:**
- Create: `tools/generate_course.py`

**Interfaces:**
- Produces: `render_page(title, body, sources) -> str`, `write_lesson(lesson) -> None`, `LESSONS` из 11 словарей.

- [ ] **Step 1: Создать структуру данных занятий**

В `LESSONS` задать для каждого занятия номер, тип, тему, целевой результат, ключевые понятия, кейс, домашнее задание и практические действия. Темы должны точно совпадать с тематическим планом спецификации.

- [ ] **Step 2: Реализовать общий HTML-каркас**

```python
def render_page(title: str, body: str, sources: list[tuple[str, str]]) -> str:
    source_items = ''.join(f'<li><a href="{url}">{name}</a></li>' for name, url in sources)
    return f'''<!doctype html><html lang="ru"><head><meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>{title}</title><style>{CSS}</style></head><body>
    <header><p class="eyebrow">Обеспечение качества функционирования компьютерных систем</p><h1>{title}</h1></header>
    <main>{body}</main><footer><h2>Источники</h2><ul>{source_items}</ul></footer></body></html>'''
```

- [ ] **Step 3: Реализовать генерацию пяти файлов урока**

`write_lesson` создаёт каталог `NN_тема` и пять файлов. Для практики методический файл строится из разделов «Цель работы», «Исходные данные», «Порядок действий», «Самопроверка», без раздела «Теория».

- [ ] **Step 4: Запустить генератор**

Run: `python tools/generate_course.py`

Expected: корневой каталог с 11 папками и HTML-файлами в каждой.
