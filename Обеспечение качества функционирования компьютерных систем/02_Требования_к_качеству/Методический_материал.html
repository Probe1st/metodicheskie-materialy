Обеспечение качества функционирования компьютерных систем

Требования к качеству по ISO/IEC 25010:2023

Что важно понять

Фраза «сервис должен быть удобным» полезна как намерение, но её нельзя проверить. Проверьте, можно ли по требованию назвать данные, действие, ожидаемый результат и условие. Если ответить нельзя, требование нужно уточнить вместе с заказчиком.

ISO/IEC 25010:2023 даёт общий словарь характеристик качества. Он не назначает единственный показатель за вас: для сервиса заказов команда сама решает, какой отклик приемлем, какие роли существуют и какие данные особенно ценны. Модель помогает не забыть характеристики, которые редко видны на демонстрации.

Хороший критерий наблюдаем. Вместо «оформление работает быстро» используйте «при каталоге из 100 товаров подтверждение заказа завершается не позднее чем через две секунды в согласованной тестовой среде». Вместо «данные защищены» — «пользователь с ролью buyer не может получить заказ другого пользователя по его идентификатору».

Требования к качеству конфликтуют. Сложный пароль повышает защиту, но ухудшает взаимодействие; подробные журналы помогают расследовать инциденты, но требуют защитить персональные данные. Конфликт не означает ошибку — его нужно сделать явным и принять обоснованное решение.

Рабочий пример

# Проверяемый критерий: чужой заказ недоступен
def get_order(order_id: int, current_user_id: int, repository):
    order = repository.get(order_id)
    if order is None:
        raise LookupError("Заказ не найден")
    if order.user_id != current_user_id:
        raise PermissionError("Доступ запрещён")
    return order

После работы с материалом вы превращаете расплывчатое ожидание в проверяемый критерий качества и связываете его с характеристикой ISO/IEC 25010:2023.

Ключевые понятия

Функциональная пригодность

Функции дают корректный и полный результат.

Эффективность производительности

Ресурсы и отклик соответствуют условиям использования.

Надёжность

Система сохраняет работоспособность в заданных условиях.

Безопасность

Данные и функции защищены от несанкционированного воздействия.

Сопровождаемость

Продукт можно анализировать, изменять и проверять.

Гибкость

Продукт можно адаптировать к средам и условиям.

Совместимость

Продукт сосуществует и взаимодействует с другими системами.

Возможность взаимодействия

Пользователь может результативно взаимодействовать с продуктом.

Безопасность использования

Продукт предотвращает неприемлемый риск вреда.

Учебный кейс

Требование звучит так: «Покупатель должен быстро и безопасно видеть историю своих заказов». Разложите его на не менее трёх измеримых критериев и укажите для каждого характеристику качества.

Порядок действий

  1. Выберите три характеристики качества из модели.
  2. Для каждой сформулируйте условие, действие и измеримый ожидаемый результат.
  3. Отметьте данные и инструменты, нужные для проверки.
  4. Проверьте, что два разных человека поймут критерий одинаково.

Самопроверка

  • Я могу объяснить, какое правило проверяю.
  • Я использую конкретные данные и ожидаемый результат.
  • Мой вывод опирается на наблюдение, а не на предположение.
