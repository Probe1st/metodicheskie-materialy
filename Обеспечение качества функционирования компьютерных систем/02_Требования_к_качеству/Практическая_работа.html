Обеспечение качества функционирования компьютерных систем

Практическая работа: Требования к качеству по ISO/IEC 25010:2023

Выполните работу как небольшой цикл проверки качества: подготовьте данные, проведите проверку, зафиксируйте факт и сделайте вывод.

Постановка

Требование звучит так: «Покупатель должен быстро и безопасно видеть историю своих заказов». Разложите его на не менее трёх измеримых критериев и укажите для каждого характеристику качества.

Исходные данные

# Проверяемый критерий: чужой заказ недоступен
def get_order(order_id: int, current_user_id: int, repository):
    order = repository.get(order_id)
    if order is None:
        raise LookupError("Заказ не найден")
    if order.user_id != current_user_id:
        raise PermissionError("Доступ запрещён")
    return order

Ход работы

  1. Выберите три характеристики качества из модели.
  2. Для каждой сформулируйте условие, действие и измеримый ожидаемый результат.
  3. Отметьте данные и инструменты, нужные для проверки.
  4. Проверьте, что два разных человека поймут критерий одинаково.
  5. Сравните полученный результат с критерием готовности и запишите вывод.

Ожидаемый артефакт

Подготовьте документ или набор файлов, в котором видны входные данные, проверка, фактический результат, ожидаемый результат и итоговое решение.

Критерии готовности

  • Результат можно воспроизвести по вашему описанию.
  • Вы отделили факты от предположений.
  • Указали хотя бы один риск или ограничение результата.
Самопроверка

Попросите одногруппника прочитать только вашу инструкцию. Если он не понимает, что проверять и как определить успех, уточните работу.
